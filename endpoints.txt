# SCMS Web API Endpoints
# Base URL: http://localhost:5140

## Auth
- `POST   /api/Auth/register`
- `POST   /api/Auth/login`
- `POST   /api/Auth/refresh`
- `POST   /api/Auth/logout`

## Dashboards
- `GET    /api/Dashboards/dashboard`               # Staff dashboard (with query filter: ?period=daily|weekly|monthly|all&month=1..12&year=2026)
- `GET    /api/Dashboards/patient-dashboard`        # Patient dashboard (auth required)

## Appointments
- `POST   /api/Appointments`                        # Book appointment
- `GET    /api/Appointments`                        # List appointments (with filters: startDate, endDate, status, patientId, pagination)
- `PATCH  /api/Appointments/{id}/status`            # Update status
- `POST   /api/Appointments/{id}/reschedule`        # Reschedule appointment
- `GET    /api/Appointments/{id}/queue-status`      # Get patient queue status
- `POST   /api/Appointments/call-next`              # Call next in queue

## Patients
- `POST   /api/Patients`                            # Add patient profile
- `PUT    /api/Patients/{id}`                       # Update patient profile
- `GET    /api/Patients`                            # List profiles (pagination)
- `GET    /api/Patients/search`                     # Search profiles by keyword
- `GET    /api/Patients/patients/{id}`              # Get patient by ID
- `GET    /api/Patients/{id}/history`               # Patient visit history
- `GET    /api/Patients/{id}/summary`               # Medical summary (JSON)
- `GET    /api/Patients/{id}/summary/html`          # Medical summary (HTML)
- `GET    /api/Patients/{id}/summary/pdf`           # Medical summary (PDF download)
- `DELETE /api/Patients/{id}`                       # Delete patient profile

## Prescriptions
- `POST   /api/Prescriptions`                       # Create prescription
- `GET    /api/Prescriptions`                       # List (with patientId filter, pagination)
- `GET    /api/Prescriptions/prescriptions/{id}`    # Get prescription details
- `POST   /api/Prescriptions/templates`             # Save template
- `GET    /api/Prescriptions/templates`             # List templates (diseaseId filter, pagination)
- `DELETE /api/Prescriptions/templates/{id}`        # Delete template
- `GET    /api/Prescriptions/{id}/pdf`              # Download prescription PDF

## Medicines
- `GET    /api/Medicines`                           # List medicines (pagination)
- `GET    /api/Medicines/search`                    # Search medicines by keyword
- `POST   /api/Medicines`                           # Create medicine
- `PUT    /api/Medicines/{id}`                      # Update medicine
- `DELETE /api/Medicines/{id}`                      # Delete medicine
- `GET    /api/Medicines/categories`                # List medicine categories
- `POST   /api/Medicines/quarantine-expired`        # Quarantine expired batches
- `GET    /api/Medicines/alerts`                    # Inventory alerts (low stock, expiry)
- `GET    /api/Medicines/batches`                   # List batches (pagination)
- `GET    /api/Medicines/batches/search`            # Search batches (with filters)
- `GET    /api/Medicines/batches/{id}`              # Get batch details
- `POST   /api/Medicines/batches`                   # Add new batch
- `PUT    /api/Medicines/batches/{id}`              # Update batch
- `DELETE /api/Medicines/batches/{id}`              # Delete batch

## Diseases
- `GET    /api/Diseases`                            # List diseases (pagination)
- `GET    /api/Diseases/search`                     # Search diseases by keyword
- `POST   /api/Diseases`                            # Create disease
- `PUT    /api/Diseases`                            # Update disease
- `DELETE /api/Diseases/{id}`                       # Delete disease

## Payments
- `GET    /api/Payments`                            # List payments (pagination)
- `GET    /api/Payments/search`                     # Search payments by keyword
- `GET    /api/Payments/{id}`                       # Get payment by ID
- `POST   /api/Payments/gateway-callback`           # Payment gateway callback
- `POST   /api/Payments/manual-proof`               # Upload manual payment proof
- `POST   /api/Payments/{id}/approve`               # Approve payment
- `GET    /api/Payments/{id}/invoice/pdf`           # Download invoice PDF

## Users
- `GET    /api/Users`                               # List users (pagination)
- `GET    /api/Users/search`                        # Search users by keyword
- `GET    /api/Users/{id}`                          # Get user by ID
- `POST   /api/Users/staff`                         # Create staff user
- `PUT    /api/Users/{id}/roles`                    # Update user roles
- `DELETE /api/Users/{id}`                          # Delete user

## FollowUps
- `GET    /api/FollowUps`                           # List follow-ups (pagination)
- `POST   /api/FollowUps`                           # Create follow-up
- `POST   /api/FollowUps/{id}/complete`             # Mark complete

## Notifications
- `GET    /api/Notifications`                       # List notifications (with includeAll, pagination)
- `POST   /api/Notifications`                       # Create notification
- `POST   /api/Notifications/{id}/read`             # Mark notification as read

## Reports (Owner-only)
- `GET    /api/Reports/appointments`               # Appointment report (JSON) — ?reportType=&date=&startDate=&endDate=&month=&year=
- `GET    /api/Reports/appointments/pdf`           # Appointment report (PDF download)
- `GET    /api/Reports/revenue`                    # Revenue report (JSON) — ?reportType=&date=&startDate=&endDate=&month=&year=
- `GET    /api/Reports/revenue/pdf`                # Revenue report (PDF download)
- `GET    /api/Reports/patients`                    # Patient list report (JSON)
- `GET    /api/Reports/patients/pdf`                # Patient list report (PDF download)
- `GET    /api/Reports/medicine-stock`              # Medicine stock report (JSON)
- `GET    /api/Reports/medicine-stock/pdf`          # Medicine stock report (PDF download)
- `GET    /api/Reports/follow-ups`                  # Follow-up report (JSON) — ?startDate=&endDate=&status=
- `GET    /api/Reports/follow-ups/pdf`              # Follow-up report (PDF download)
- `GET    /api/Reports/prescriptions`               # Prescription report (JSON)
- `GET    /api/Reports/prescriptions/pdf`           # Prescription report (PDF download)
- `GET    /api/Reports/business-summary`            # Monthly business summary (JSON) — ?month=&year=
- `GET    /api/Reports/business-summary/pdf`        # Monthly business summary (PDF download)

## MCP (Model Context Protocol — Owner-only)
- `GET    /api/mcp/tools`                           # List available MCP tools
- `POST   /api/mcp/tools/call`                      # Call an MCP tool
- `POST   /api/mcp/chat`                            # AI chat interaction

## SignalR Hubs (Real-time WebSocket)
- `/hubs/queue`                                     # QueueHub — appointment queue updates
- `/hubs/notifications`                             # NotificationsHub — live notification delivery

## Dev & Health Endpoints
- `GET    /health`                                  # ASP.NET Core health check
